# Googleカレンダー連携（面談予約）の設定

予約先の種類を「このシステムで空き枠を選ぶ」にすると、見積で通過した応募者が管理画面で作った空き枠から面談日時を選べます。予約が入ると、連携した Google アカウントのカレンダーに予定が自動で入り、応募者が招待されます（Google Meet のリンク付き）。

連携しなくても予約自体は受け付けられます。その場合、カレンダーへの登録と、カレンダーの既存の予定との重なりの確認は行われません。

## 仕組み

- 予約の確定はこのシステムの中で行います。Google が一時的に使えなくても予約は失敗にせず、カレンダーへの登録は `partner:sync-calendar`（毎分）が最大5回まで再試行します。それでも失敗した予約は「面談日程」画面に表示され、社内通知先へメールが届きます。
- 予定IDはこのシステムで決めて送るため、再試行しても予定が二重にできません。
- 応募者に見せる空き枠からは、カレンダーで予定が入っている時間帯と重なる枠を自動で除きます（予約時にも確認します）。
- 管理者が予約を取り消すと、枠は空きに戻り、カレンダーの予定も削除されます（Google から応募者へ取り消しの通知が届きます）。
- このシステムが Google に求める権限は「予定の作成・削除」と「空き時間の確認」だけです。カレンダーの予定の中身は読みません。
- 連携情報（リフレッシュトークン）は暗号化して保存します。`APP_KEY` を変えると読めなくなるため、その場合は連携し直してください。

## 設定手順（最初に1回）

画面の名前は Google 側の変更で変わることがあります。

1. 面談の予定を入れたい Google アカウントで [Google Cloud コンソール](https://console.cloud.google.com/) にログインし、新しいプロジェクトを作ります（名前は例えば `phoenix-partner`）。
2. 「API とサービス」→「ライブラリ」で **Google Calendar API** を検索し、「有効にする」を押します。
3. 「Google Auth Platform」（または「OAuth 同意画面」）を開き、アプリ名・サポート用メールを入力します。
   - 対象（ユーザーの種類）は、Google Workspace のアカウントなら「内部」、無料の Gmail アカウントなら「外部」を選びます。
   - 「外部」の場合、動作確認だけなら公開ステータスは「テスト中」のままで構いません。「対象」の「テストユーザー」に連携するGmailアドレスを追加してください。ただし「テスト中」は7日ほどで連携が切れるため、その都度「Googleと連携する」を押し直す必要があります。
   - 本番で使うときは「アプリを公開」で本番環境にします。公開には「ブランディング」でホームページURL・プライバシーポリシーURL（会社サイトのもの）と、そのドメインを「承認済みドメイン」に登録しておく必要があります。未確認のアプリとして警告画面が出ますが、自社の管理者だけが使うので「詳細」→「（アプリ名）に移動」で進めて問題ありません。
4. 「クライアント」→「クライアントを作成」で、種類に **ウェブアプリケーション** を選び、「承認済みのリダイレクト URI」に次を追加します。
   - ローカル：`http://localhost:8000/admin/google/callback`
   - 本番：`https://（本番のドメイン）/admin/google/callback`
5. 作成後に表示される **クライアントID** と **クライアントシークレット** を、`.env` の `GOOGLE_CLIENT_ID` と `GOOGLE_CLIENT_SECRET` に貼り付けて保存します。シークレットは他人に見せないでください。
6. 管理画面の「面談日程」を開き、「Googleと連携する」を押します。Google の画面でアカウントを選び、表示されるすべての項目にチェックを入れて許可します。「連携中：（アカウント）」と表示されれば完了です。
7. 管理画面の「設定」で、予約先の種類を「このシステムで空き枠を選ぶ」にします。
8. 「面談日程」で、期間・曜日・時間帯・1枠の長さを指定して空き枠を作ります。

## 運用メモ

- 予約の締切（開始の何時間前まで予約できるか）は「面談日程」画面で変えられます。初期値は24時間です。
- 応募者からの日程変更の依頼は、管理者が予約を取り消してから、応募者に選び直してもらいます（取り消すと、応募者は同じ専用URLから別の枠を選べます）。
- 連携を解除すると、それ以降の予約はカレンダーに登録されません。既にある予定は消えません。
